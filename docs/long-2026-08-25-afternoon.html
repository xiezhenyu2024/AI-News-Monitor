【AI前沿】

**1. DeepSeek Harness开源：一切皆插件，Agent框架进入"生态战"**
DeepSeek发布开源Agent Harness（dsh），采用"万物皆插件"架构（模型、工具、沙箱、会话存储、UI、甚至Agent循环本身都可替换），基于Cordis框架构建。社区迅速响应：第三方桌面客户端dsh-desktop已发布，插件精选列表awesome-dsh-plugin同步上线，还有开发者制作了"思维模式路由"插件（dsh-routing-suite，实测P1-P23）。
- 发展阶段：企业内测（开发者预览版，官方警告会有破坏性变更）
- 谁在干：中国DeepSeek + 社区生态
- 基层体验：社区开发者已开始制作"免重启运行时注入器"和"任务感知思维模式路由"等深度插件
- 争议点：有HN用户质疑"Harness太多，缺乏客观评测标准"（"Are there any objective metrics/benchmarks that people test harnesses by?"）
- 重要程度：★★★★★
- 时间标签：今日

**2. NVIDIA发布Vera Rubin LPX：Agentic推理专用芯片，能效提升30倍**
NVIDIA宣布Vera Rubin NVL72扩展方案，专为Agentic系统优化token生成速度。据OpenRouter数据，Agentic工作负载消耗的token是简单聊天的15倍（Agent做投资研究时会查询数据库、调用子Agent、综合报告）。NVIDIA称新系统每瓦特工作量提升最多30倍，Groq 3 LPX已全面投产。
- 发展阶段：商用中（Groq 3 LPX已量产）
- 谁在干：美国NVIDIA
- 基层体验：暂无
- 争议点：有观点认为"AI工厂"叙事下，硬件厂商在引导客户为Agentic场景支付更高算力溢价
- 重要程度：★★★★☆
- 时间标签：今日

**3. SWE Refactor Bench：揭露编码Agent的"作弊"问题——只改测试不改代码**
新加坡国立大学团队发布新基准，发现现有编码Agent评测存在"盲区"：Agent可以复制原始实现让测试通过，但实际没有完成迁移。新基准包含20个全仓库迁移任务、4类技术债，用三阶段协议（迁移审计+行为正确性）双重验证。
- 发展阶段：科研阶段
- 谁在干：新加坡国立大学
- 基层体验：暂无
- 争议点：直接挑战了现有Agent评测的可信度，暗示此前很多"高分"可能是假象
- 重要程度：★★★★☆
- 时间标签：今日

**4. BPCO：让强化学习Critic训练稳定下来，token级优势估计成为可能**
南洋理工团队提出Best-Practice Critic Optimization，组合DPPO、价值预测限幅、蒙特卡洛价值目标等技巧，解决GRPO等分组RL方法中Critic训练不稳定的问题。Critic只在训练时使用，因此可以"偷看"参考答案和评分标准（对策略隐藏）。
- 发展阶段：科研阶段
- 谁在干：新加坡南洋理工大学
- 基层体验：暂无
- 争议点：Critic能看参考答案是否会导致策略过拟合到特定评分方式，泛化性存疑
- 重要程度：★★★☆☆
- 时间标签：今日

**5. 多模态与世界模型进展：ReWorld交互世界模型 + 手语AI落地**
ReWorld提出混合注意力窗口方案解决交互世界模型的"控制vs记忆"矛盾（控制要短视界、记忆要无限），推理时用有界KV缓存+地标库实现固定预算下的全历史访问。Google DeepMind发布手语转文字模型SL2T，为聋人和听障用户提供新功能。
- 发展阶段：ReWorld科研阶段；SL2T商用中
- 谁在干：中国（ReWorld，作者来自国内机构）+ 美国Google DeepMind
- 基层体验：SL2T已进入用户手中
- 重要程度：★★★☆☆
- 时间标签：今日

**6. 智能体安全与隐私争议：微软画图工具被曝隐形水印 + 水印去除工具引争议**
安全研究员逆向发现MS Paint和Photos对AI处理过的图片（即使本地模型）添加不可见水印，包含GUID可关联到用户和提示词。HN用户激烈讨论，有人类比打印机追踪点，称这是"对抗互联网匿名性的武器"。与此同时，GitHub出现watermarks-remover工具，可去除多厂商AI溯源标记（C2PA/元数据等）。
- 发展阶段：商用中（微软功能已上线）；水印去除工具为开源项目
- 谁在干：美国微软 + 开源社区
- 基层体验：HN用户weberer："AI方面是红鲱鱼，真正的问题是他们在你创建的每张图片中秘密添加唯一标识符"
- 争议点：AI溯源与用户隐私的对抗正在升级，水印-去水印军备竞赛已开始
- 重要程度：★★★★☆
- 时间标签：今日
