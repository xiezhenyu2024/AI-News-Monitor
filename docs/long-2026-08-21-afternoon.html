**1. DeepSeek Harness 公测一周迎来多模态大招，插件生态爆发**
DeepSeek Harness 发布 v0.1.0-rc.8，14项更新中多模态是重头戏：支持原生图片请求和图文混合输入，/goal、/plan 等命令可直接接收图片；Claude Code 和 Codex 进一步接入子 Agent 体系；Windows 终端加入持久 PowerShell 会话。GitHub 上该项目已斩获 17.5 万 Star，配套的桌面端方案（deepseek-harness-desktop，1.6万星）和插件精选列表（awesome-dsh-plugin，1万星）同步走红，掘金上出现了安装配置保姆教程和"15款值得安装的插件"等实操内容。

**4. AI 内容溯源攻防战：水印移除工具与版权争议并行**

争议点：水印移除工具是否助长 AI 内容滥用，与 EU 版权裁定形成政策与技术层面的双重博弈

【实战速报】

🛠️ **Claude Code 三个月实战：Agent 不是鲁莽，是看不见爆炸半径**
开发者 Rabih Jabr 将 Claude Code 作为日常驱动工具使用了三个月，用它编写 Ansible 配置。他发现 Agent 的问题不是"鲁莽"，而是"看不见爆炸半径"——它无法预判一个操作可能引发的连锁影响。他的解法是给 Agent 更明确的边界约束和更细粒度的执行步骤。
来源：Dev.to

🛠️ **腾讯云 OCR Skills 实战：几分钟完成投标审查**
掘金用户分享了自己用 WorkBuddy 配合腾讯云 OCR Skills 完成投标审查的全过程。OCR（光学字符识别，将图片中的文字提取为可编辑文本的技术）技能让 Agent 能直接"读"扫描件，将原本需要数小时的文档审查压缩到几分钟。
来源：掘金

🛠️ **GitMCP 实战：让 AI Coding Agent 直接访问 CAD 文档**
掘金上出现了一篇 GitMCP 实战指南，教开发者如何让 AI Coding Agent 直接访问 CAD（计算机辅助设计）文档。通过 GitMCP 协议桥接，Agent 可以读取和操作原本无法直接访问的专业设计文件格式，解决了 Agent 在工程设计场景中的"数据盲区"问题。
来源：掘金

【开发者讨论】

HN 上关于"训练 125M 模型自动完成钢琴演奏"的讨论热度很高。有评论指出这种"自动补全"本质上是古典作曲家训练的基础方法，推荐阅读 Robert Gjerdingen 的 Gebrauchs-Formulas 一文；也有钢琴家兼产品设计师看到 AI 音乐工具与 AI UX 设计工具的共通性——"生成"的门槛降低后，核心价值转向了策展与判断。还有开发者建议通过 Web MIDI 在浏览器中运行该模型，因为 125M 参数规模在浏览器端完全可行。

Dev.to 上另一篇热帖"Your agent isn't reckless. It just can't see the blast radius"引发共鸣，多位开发者分享了类似的 Agent 边界控制经验。此外，"Your Memory API Is Lying to Your Agent"一文指出记忆存储接口可能在丢弃关键信息，导致 Agent 的"记忆"失真。
