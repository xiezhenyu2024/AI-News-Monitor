【AI前沿】

**1. DeepSeek V4-Flash 补上视觉能力，多模态逼近 Opus 4.8**
DeepSeek 今日发布实验性模型 `deepseek-v4-flash-vision-exp`，纯文本能力不降级，视觉能力大幅跃升，多模态 Agent 综合表现接近 Opus 4.8。同时 DeepSeek Harness 生态持续膨胀（18.2万星），配套桌面端、插件精选列表、路由套件等周边工具密集涌现。
- 发展阶段：商用中（API 已开放）
- 谁在干：中国 DeepSeek
- 基层体验：掘金多篇教程称"一条命令装 595 个插件""本地跑 Qwen 3.8 拥有 Opus 4.6"，社区热度极高
- 争议点：视觉补强是"实验版"，稳定性待验证；Harness 生态虽大但插件质量参差
- 重要程度：★★★★★
- 时间标签：今日

**2. 递归自改进（RSI）首次有了专属基准：AI4AI-Bench**
（前提：RSI 指 AI 系统能否改进"产生 AI 的训练算法"本身）新基准专门测试 LLM Agent 设计训练算法的能力，填补了此前无基准可隔离该能力的空白。同期 FlowEvo 提出免训练框架，让工作流与技能在推理时协同进化，把成功流程编译为可复用技能存入持久库。
- 发展阶段：科研阶段
- 谁在干：学术界（多机构）
- 基层体验：暂无
- 争议点：RSI 可行性本身存疑，基准能否真正衡量"改进能力"有争议
- 重要程度：★★★★☆
- 时间标签：今日

**3. 医疗 AI 双线推进：患者导向报告解读 + 75M 患者 EHR 可解释模型**
G-CARL 提出"患者导向医学报告解读"（PMRI）新任务，要求模型兼顾医学事实性与患者沟通语境；BERT-LER 则在 7500 万患者去标识化 EHR 上预训练，将化验结果编码为离散 token 并保留分级信息，强调可解释性。
- 发展阶段：科研阶段
- 谁在干：学术界
- 基层体验：暂无
- 争议点：PMRI 任务定义是否覆盖真实临床沟通复杂度
- 重要程度：★★★☆☆
- 时间标签：今日

**4. Agent 路由与任务建模：成本感知路由 + 从操作痕迹归纳任务模型**
Pandora's Box 研究多模型路由中"价值估算本身有成本"的权衡——廉价估算快但噪声大，精确估算贵但准。另一研究从自然计算机操作痕迹（截图+鼠标键盘）归纳符号化、可审计的任务模型，供 Agent 学习真实工作流。
- 发展阶段：科研阶段
- 谁在干：学术界
- 基层体验：暂无
- 争议点：路由估算成本与收益的平衡点难定；痕迹归纳在真实杂乱工作流中鲁棒性存疑
- 重要程度：★★★☆☆
- 时间标签：今日

**5. 概念级遗忘基准 ConceptGuard + 模型路由开源方案**
ConceptGuard 指出现有 LLM 遗忘评测只用"不相交的独立事实"过于简单，提出上下文敏感遗忘基准。开源侧 sprix-sage-router 提供状态感知的 SELF/COLLABORATE/HANDOFF 路由方案。
- 发展阶段：科研阶段（ConceptGuard）/ 企业内测（sprix）
- 谁在干：学术界 + 开源社区
- 基层体验：暂无
- 争议点：遗忘评测的"上下文敏感"如何量化仍无共识
- 重要程度：★★★☆☆
- 时间标签：今日
