与你相关：奖励黑客会污染 AI 评测结果，让模型能力被高估，该研究提供了一种基于内部表征的检测手段。

#6 论文提出 ComPO：基于比较的零阶 LLM 偏好对齐方法

关键实体
  • ComPO：一种新的偏好对齐方法，通过比较而非直接优化偏好损失来提取方向信息
  • 零阶优化：不需要计算梯度、只依赖函数值比较的优化方法，适合黑箱或不可微场景
  • 偏好对齐：让大模型的输出符合人类偏好和价值观的训练过程

论文提出并分析 Comparison-based Preference Optimization（ComPO），一种基于比较 oracle 的零阶偏好对齐方法。ComPO 不直接优化可微偏好损失，而是从偏好对中提取方向信息，作者在平滑性、梯度稀疏性和兼容性假设下证明了离线方案的收敛性，并进一步提出在线 ComPO，利用无标注策略生成做反向 KL 控制。

与你相关：偏好对齐是大模型训练的核心环节，零阶方法可能降低对梯度和显存的需求，为对齐提供新思路。

#9 研究显示架构干预可改变大模型预训练缩放指数，7.4B模型以20倍更少算力追平GPT-3 13B

关键实体
  • Scaling Laws（缩放定律）：描述模型性能如何随计算量、参数量、数据量增加而提升的经验规律，通常认为指数固定不变
  • Looped Transformer（循环Transformer）：让同一组网络层重复执行多次的Transformer变体，相当于用递归深度换取模型容量
  • Model Growth（模型增长）：训练过程中动态增加模型规模（如增加循环次数）的技术
  • Boundary Operator（边界算子）：一种对早期网络块的输出做归一化并重新注入后续层的简单操作
  • CORE：一个评估语言模型能力的基准测试集

该研究挑战了缩放定律中指数固定的传统认知，证明架构干预可以改变预训练缩放指数，从而带来指数级的性能提升。作者以循环Transformer为切入点，发现训练中增加循环次数（模型增长）对缩放指数影响最大。一个7.4B的模型增长架构在CORE基准上以约20倍更少的算力追平GPT-3 13B，且算力效率增益随规模增大而增加。

与你相关：若缩放指数可被架构设计改变，意味着大模型竞争的关键可能从堆算力转向架构创新，对算力受限的研究者和公司意义重大。

#10 SpectralShift通过谱重参数化实现Gated DeltaNet上下文窗口高效扩展

关键实体
  • Gated DeltaNet（GDN）：一种线性注意力架构，用状态转移矩阵替代softmax注意力，适合长上下文建模
  • SpectralShift：本文提出的谱重参数化方法，通过调整衰减谱来扩展GDN的上下文窗口
  • Linear Attention（线性注意力）：计算复杂度随序列长度线性增长的注意力机制，比标准softmax注意力更适合长文本
  • Spectral Reparameterization（谱重参数化）：通过重新参数化模型参数来改变其频谱特性（如衰减速度）的技术
  • Continual Pretraining（持续预训练）：在已有预训练模型基础上继续训练以扩展能力（如更长上下文）的过程

线性注意力层正被越来越多地用于替代softmax注意力以支持长上下文建模，但现有上下文扩展方法通常直接持续预训练而不修改这些层，忽视了线性注意力状态动态的谱特性。本文从转移矩阵的谱视角研究Gated DeltaNet的长上下文扩展，识别出两个关键因素：与目标依赖长度对齐的足够宽的慢谱带，以及保留用于状态清除和上下文切换的快衰减模式。基于此提出SpectralShift，通过重参数化alpha投影初始化来重塑衰减谱，增强慢速传播能力。

与你相关：为线性注意力架构的长上下文扩展提供了理论视角和实用方法，对降低长文本建模成本有直接价值。

#18 研究突破三值 LLM 的 1.58-bit 量化壁垒

关键实体
  • 三值 LLM（Ternary LLM）：权重只用 -1、0、1 三个值表示的大模型，体积极小、计算极快
  • 1.58-bit：三值量化的理论信息熵下限，表示每个权重平均只需约 1.58 个比特存储
  • 量化：把模型参数从高精度压缩到低精度，以减少内存占用和加速推理的技术

一篇 arXiv 论文提出突破三值 LLM 1.58-bit 量化壁垒的新方法。三值量化将模型权重限制为 -1、0、1 三个值，可大幅压缩模型体积并加速推理，但 1.58-bit 长期被视为该方向的理论极限。该研究尝试在这一极限之外寻找新的可能性。

与你相关：三值量化是极端模型压缩的前沿方向，突破 1.58-bit 壁垒可能让大模型在边缘设备和低功耗场景下的部署更加可行。

#24 开源项目 codex-with-chatgpt 让 ChatGPT 网页版负责规划、Codex 负责执行，节省 API 额度
