【实战速报】
🛠️ 开发者用 Codex + ChatGPT 网页版"双打"省 API 额度
做法：把"思考/规划/Review"交给已付费的 ChatGPT 网页版，Codex 只负责执行，通过只读 MCP 桥接，不用 API Key、不做逆向代理。
解决：ChatGPT Plus/Pro 网页额度闲置、Codex API 额度紧张的矛盾。
感受：官方网页 + 只读桥接，规避了封号与合规风险。
来源：GitHub（XiaoDuoYa/codex-with-chatgpt）

🛠️ 开发者给多 Agent 系统加"按 Agent 计费追踪"，抓出 1.4 倍静默浪费
做法：在 AWS Bedrock + Strands 多 Agent 编排中，为每个 Agent 单独做成本追踪，只读、零成本。
解决：系统返回 200 OK 且答案完美，账单却多出约 1.4 倍——定位到静默浪费。
感受：一周投入换来对"看不见的烧钱"的可见性。
来源：Dev.to（Sarvar Nadaf）

🛠️ 开发者用 Jev 决策模型替换 Claude Code 的压缩摘要，保住逐字上下文
做法：fast-jev-compaction 插件对每次工具调用与结果打分，只删除/截断过时项，保留内容一律逐字保留，用户与助手文本原样有序。
解决：传统 LLM 摘要式压缩会丢失文件路径、精确报错、约束等关键信息。
感受：不重写、只删除，上下文更可靠。
来源：GitHub Trending（tamaratran/fast-jev-compaction）
