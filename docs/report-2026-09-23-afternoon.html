#4 OpenAI 为 GPT-6 改进提示缓存机制

关键实体
  • 提示缓存（Prompt Caching）：把重复使用的提示内容缓存起来，避免每次重新计算，从而降低延迟和费用
  • 缓存命中率：请求中成功命中已有缓存的比例，越高越省钱省时间
  • 断点（Breakpoints）：开发者手动指定缓存位置的控制点，用于精细管理缓存策略

OpenAI 为 GPT-6 推出改进版提示缓存功能，提升了缓存命中率，新增诊断工具和显式断点控制。开发者可以更精细地管理缓存策略，从而降低调用延迟和成本。

#6 Flash-dLLM：为扩散语言模型提速的免训练推理框架

关键实体
  • 扩散语言模型（dLLM）：一种非自回归的文本生成模型，与逐字生成的 GPT 类模型原理不同，可并行生成文本
  • KV 缓存：缓存注意力计算中的键值对，避免重复计算，是大模型推理加速的核心手段
  • 并行解码：同时生成多个 token 而非逐个生成，用于提升推理速度

研究者提出 Flash-dLLM，一个免训练的推理加速框架，专为扩散语言模型设计。该框架识别出 GPU 显存 I/O 是 KV 缓存场景下的主要瓶颈，通过 I/O 感知的融合缓存内核减少冗余内存搬运，并结合 KV 缓存驱动的草稿-验证机制实现高效并行解码。

与你相关：扩散语言模型被视为自回归模型的潜在替代方案，但推理效率一直是其落地的主要障碍。

#7 新研究：用强化学习训练概念生成器，提升大模型推理探索效率

关键实体
  • 重复采样（Repeated Sampling）：让模型对同一问题生成多个答案，从中挑选正确的一个，是目前提升推理准确率的主流方法
  • 概念生成器：一个小模型，负责在解题前生成思路、提示或策略，引导大模型作答
  • 强化学习：通过奖励信号训练模型做出更优决策的机器学习方法

研究者指出，当前大模型处理难题时依赖的重复采样策略存在缺陷：由于只在局部解码噪声中探索，容易产生大量近似重复的答案而非真正不同的思路。论文提出在语义层面引导探索，先采样问题相关的概念、提示或策略，再据此生成答案，并用强化学习训练一个小型概念生成器，使其生成的概念能最大化下游大模型的解题成功率。

与你相关：该研究针对的是大模型推理的核心瓶颈——如何在有限算力下探索更多有效解法。

#9 研究揭示MCP生态供应链风险：A2M框架可劫持AI代理，恶意工具调用率高达93.6%

关键实体
  • MCP：Model Context Protocol，一种让AI代理从第三方服务器选择和使用工具的标准协议
  • A2M：Attraction-to-Manipulation，一种两阶段黑盒攻击框架，通过优化工具元数据和返回结果来劫持AI代理

  • GLM-4.6：智谱AI开发的大语言模型，此处作为攻击测试的目标模型

研究者提出A2M框架，通过优化工具元数据（吸引阶段）和利用执行轨迹精炼恶意返回（操纵阶段），对使用MCP协议的AI代理实施黑盒劫持。在LiveMCPBench上，针对GLM-4.6的测试显示恶意工具调用率达93.6%，认知拒绝服务攻击下token成本增至32.4倍，信息窃取等场景平均攻击成功率达74.4%，且可迁移至其他四个模型。

与你相关：随着AI代理广泛采用MCP协议调用第三方工具，语义供应链攻击成为现实威胁，该研究揭示了协议层面的系统性安全漏洞。
