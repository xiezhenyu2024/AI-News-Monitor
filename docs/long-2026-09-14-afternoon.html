【实战速报】

🛠️ 开发者用 Qodo 把编码 Agent 变成"自己的第一个 Reviewer"
思路是"左移代码审查"：让 Agent 在提交前先自审，把审查环节从人工前置到 Agent 内部。作者认为 AI 编程普及后，审查方式必须随之改变。
来源：Dev.to（Kiran Naragund）

🛠️ 开发者厘清"Agent 编排器"与"Agent 协调器"不是同一层
作者指出：只跑一个编码 Agent 时两者都不需要；一旦多 Agent 并行，编排（orchestrator）负责调度任务流，协调（coordinator）负责避免冲突，混为一谈会导致架构错误。
来源：Dev.to（Nick Woodhead）

🛠️ 开源中国社区：Casdoor v4 内置 MCP Server 与 Agent 鉴权
Casdoor v4.0 于 9 月 1 日发布、9 月 9 日迭代至 v4.3，控制台全面重写，新增 MCP Server 与 Agent 鉴权能力，项目已收录进 CNCF 云原生全景图。对正在搭 Agent 系统的开发者来说，身份与权限这一层终于有了现成方案。
来源：开源中国

【开发者讨论】

【Dev.to / HN】"Vibe Coding 不是问题，把它叫工程才是问题"引发共鸣
多位开发者围绕 AI 编程展开反思：AI 写代码速度远超人类，但"编码从来不是软件最有价值的部分"；有人指出 AI 揭示的真相是——速度被高估，判断力被低估。核心分歧在于：AI 已经比多数开发者更会写代码，但这是否等于更会做工程。
来源：Dev.to（Giorgi Kobaidze、Sylwia Laskowska、Cesar Aguirre）

【智能体与大模型对比】

今日素材显示两条清晰路线：OpenAI 的 GPT-6 Astra 走"深度嵌入企业生产系统"路线，Perplexity 与 Cognition 的反馈均强调"检查频率降低"，即模型可靠性已足以承担端到端职责；而开源侧则聚焦 Agent 协作基础设施——OpenBot 给每个 Agent 独立电脑与权限、Sprix SAGE Router 做 A2A 网络的中途重路由、Cumora 把 Agent 当团队一等成员、agent-memory 让 Claude Code 与 Codex 共享同一记忆库。前者是"模型变强"，后者是"Agent 变组织"，两条路线正在同时推进。

【开源项目】

- CopilotKit/OpenBot - 开源 AI 同事，每个 Agent 拥有独立浏览器、文件与工具权限，动作先决策后记录，可接入任意 AG-UI Agent。
- yetone/cumora - Agent 团队协作聊天平台，Agent 与人类同花名册、同私信、同看板，支持云端或自带 Claude Code / Codex 大脑。
- tigerless-labs/agent-memory - Agent 长期记忆运行时，以纯 Markdown 为真相源，Claude Code 与 Codex 共享同一存储，无需 API Key。
- sapientinc/PRAXIST - 面向可测量、可计算机执行研究的自主研究系统，定位"你的个人研发团队"。
- xzf-thu/VoiceMem - 下一代语音 Agent 记忆基础设施，分左右脑分别存储信息与情感，全流式架构消除延迟。
