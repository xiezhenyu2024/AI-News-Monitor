【前言】
今天最值得关注的趋势是：智能体从"能跑通"进入"可管控、可复用、可验证"的工程化阶段，围绕记忆、编排、验证与成本控制的基础设施集中爆发。

【AI前沿】
【ArXiv + 开源中国】智能体"记忆与判断层"成为研究热点，多篇论文与开源项目同时指向同一方向。
技术内容：ArXiv 提出 Designer-RSI（从用户流量中演化程序性记忆，让冻结的前沿模型通过230+工具操作专业设计软件，外部自然语言技能记忆持续积累与修正）；另一篇提出 MDL（记忆决策层：在检索与生成之间加一个零参数控制器，融合相关性、可靠性、一致性三信号，避免RAG盲目注入冲突记忆放大幻觉）。开源中国则报道 Jev 判断模型（不生成文本、只做"选择/打分"的判断层）正在给 Codex、BrowserUse 提速。
发展阶段：科研阶段（论文）＋企业内测（Jev 类判断层）
谁在干：高校研究团队（Du、Yan等）＋ TypeSafe AI 等创业公司
基层体验：开发者晒出用 Jev 改造 Codex/BrowserUse 后"速度暴涨"的截图，相关开源项目几天内破万星。
争议点：记忆该"存更多"还是"更会判断该不该信"，两派路线尚未收敛。
重要程度：★★★★☆
时间标签：今日

【ArXiv + 开源中国】编程智能体的强化学习环境与"自进化"训练成为新焦点。
技术内容：CodeMidas 提出仅以源码为输入，把代码库中已实现的功能自动转成可执行 RL 环境（智能体探索功能→构造行为规格→基于原始代码执行生成测试→验证过滤任务），解决 RL 训练任务稀缺问题；这与追踪中的 MiMo-Code"模型与Agent协同进化"、shadcn/improve"审计→修复"工作流属同一脉络。
发展阶段：科研阶段
谁在干：Bowen Ye 等研究团队；小米 MiMo-Code 等企业项目
基层体验：暂无直接一手反馈
争议点：自动生成的任务验证器是否足够可靠，仍待检验。
重要程度：★★★★☆
时间标签：今日

【DeepMind + NVIDIA + OpenAI】大厂同日多线推进：模型、算力、行业落地齐发。
技术内容：DeepMind 发布 Gemini 3.8 Live 与 3.8 Live Extended Thinking（实时＋扩展思考）、WeatherNext 3 天气模型、AlphaGenome Atlas（绘制人类基因组90亿个单字母DNA变异的分子效应）；NVIDIA 的 Vera Rubin NVL72 在 MLPerf Inference v6.1 首秀领先，并联合 Emerald AI、Google 成立 AI 能源管理联盟（AEMA）；OpenAI 推出 Astra for Law（法律版前沿智能）与澳大利亚青年安全蓝图。
发展阶段：商用中
谁在干：Google DeepMind、NVIDIA、OpenAI

争议点：MIT 科技评论同期追问"AI 真会毁灭人类吗"，行业一边加速一边自我质疑。
重要程度：★★★★★
时间标签：今日

【实战速报】
🛠️ 开发者用"ChatGPT 思考 + Codex 干活"的混合工作流省钱
XiaoDuoYa 开源 codex-with-chatgpt：把规划与 Review 交给已付费的网页版 ChatGPT，Codex 只负责执行，通过官方网页＋只读 MCP 桥接，不用 API Key、不做逆向代理。解决的问题是"ChatGPT 网页额度闲置、Codex API 额度紧张"。作者称更新到最新版可解决大多数已知问题。
来源：GitHub Trending

🛠️ 开发者用 Jev 判断层给 Agent 提速
据开源中国报道，开发者把 Jev（不生成文本、只做选择与打分的判断模型）接入 Codex、BrowserUse，用一次快速请求对每个工具调用与结果打分，丢弃或截断过时内容、保留内容逐字不改。相比传统"让 LLM 总结旧对话"的有损压缩，它不重写任何内容，避免文件路径、报错、约束在压缩中丢失。
来源：开源中国

🛠️ 开发者用 fast-jev-compaction 插件替换 Claude Code 的压缩摘要
tamaratran 发布 Claude Code 插件，用 Jev 决策替代 compaction 摘要：每个工具调用和结果在一次快速请求中被打分，过时的被丢弃或截断，保留的全部逐字保留，同时也可作为 npm 库使用。
来源：GitHub
