#1 SWE-Prime提出多粒度两阶段数据筛选方法，用更少轨迹提升大模型软件问题解决能力

关键实体
  • SWE-Prime：一种用于大语言模型训练数据筛选的新方法，通过两阶段筛选提升模型性能
  • SFT：监督微调，用标注好的数据训练模型的方法
  • ArXiv：学术论文预印本平台，研究者发布最新研究成果的地方

SWE-Prime提出一种多粒度两阶段监督微调数据筛选方法，针对大语言模型解决真实软件问题场景。该方法先按过程质量、结果质量和数据代表性筛选高质量成功轨迹，再在片段层面进行精细筛选。实验表明，用更少的训练轨迹即可获得更好的模型性能，解决了成功轨迹中可能包含无效或冗余步骤导致的噪声监督问题。

#6 PILOT框架实现长时程AI智能体的实时自我改进

关键实体
  • PILOT：一种监督者-执行者架构，让AI智能体在执行过程中实时自我改进
  • Hugging Face：全球最大的AI模型和数据集开源社区平台
  • 长时程任务：需要多步骤、长时间才能完成的复杂任务

PILOT提出一种监督者-执行者架构，实现长时程AI智能体的实时自我改进。该架构通过两个耦合机制：实时引导让独立监督者能在执行过程中重定向或中止执行者，实时自我进化将执行中暴露的程序和失败模式提炼为可复用技能。这种方法能在任务执行过程中即时应用经验，而非等到执行结束后才处理。

与你相关：该研究突破了现有自我改进方法只能在执行结束后处理经验的局限，为长时程AI智能体的实时优化提供了新方案。
