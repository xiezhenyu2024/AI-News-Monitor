#10 Hugging Face 论文提出仅用 1% token 即可高效完成在线策略蒸馏

关键实体
  • 在线策略蒸馏（OPD）：一种让小型学生模型在自己生成的输出上接受大型教师模型指导的训练方法，用于提升小模型能力
  • 信息效率比（IER）：论文提出的新指标，基于信噪比分解来衡量梯度估计的相对误差，用于判断哪些 token 值得接受教师指导
  • token：语言模型处理文本的基本单位，可以是一个词、一个字或词的一部分
  • 反向 KL 散度：衡量两个概率分布差异的数学指标，在蒸馏训练中用于约束学生模型向教师模型靠拢

该研究针对稀疏在线策略蒸馏中梯度估计噪声问题，提出信息效率比（IER）指标，基于信噪比分解评估每个 token 的梯度估计可靠性。结合 IER 与现有 token 选择策略后，在数学和医学推理任务上，仅用 0.1%–1% 的 token 预算即可匹配甚至超越全量 OPD 的效果。

与你相关：大幅降低蒸馏训练的计算成本，使小模型高效获取大模型能力成为可能，对资源受限场景下的模型训练有直接价值。

#11 Critical-State RL：诊断多轮工具调用中哪些状态真正值得训练

关键实体
  • Critical-State RL：论文提出的强化学习方法，用于识别多轮交互中哪些模型调用状态是真正可训练的
  • 多轮工具使用：AI 模型在完成任务时需要多次调用外部工具（如搜索、计算器）的交互模式
  • 嵌套采样：一种统计采样技术，用于分离动作相关的奖励变化与后续交互带来的随机噪声
  • BFCL v4：Berkeley Function Calling Leaderboard 第四版，评估大模型工具调用能力的公开基准测试

论文提出 Critical-State RL 方法，解决多轮工具调用中奖励变化无法区分'当前动作好坏'与'后续随机性'的问题。该方法通过嵌套采样分离动作相关奖励变化与延续噪声，在诊断选定的状态上用上下文赌博机训练优化策略。在 BFCL v4 基准上，诊断选定的状态训练效果优于替代状态。

与你相关：多轮工具调用是 AI Agent 的核心能力，精准定位可训练状态可大幅提升训练效率和 Agent 可靠性。

#13 onPanda：通过 token 级修正将 LLM 对齐数据标注时间缩短 52%

关键实体
  • onPanda：论文提出的交互式标注工具，通过 token 级修正高效生成 LLM 对齐数据
  • 在线策略数据：由模型自身生成（而非人工从头编写）的训练数据，能保持模型的输出分布特征
  • SFT：监督微调，用标注数据对预训练大模型进行有监督训练以提升特定任务表现
  • token 级修正：标注者定位模型输出中第一个不合适的 token，替换或修改后让模型从该位置继续生成

论文提出 onPanda 交互式标注工具，核心机制为 token 级修正：标注者定位第一个不合适的 token 并修正，系统截断后续内容并从修正处继续生成，循环直至满意。小规模对照实验显示，相比人工后期编辑，onPanda 将中位标注时间缩短 52%，且生成数据保留了模型采样分布，适合构建在线策略 SFT 和偏好数据。

与你相关：LLM 对齐训练高度依赖高质量标注数据，降低标注成本可加速模型迭代，尤其对 Agent 轨迹标注有实用价值。

#15 DolphinBench：首个通过任务完成度评估 Agent 记忆能力的基准

关键实体
  • DolphinBench：论文提出的 Agent 记忆评估基准，通过任务完成度而非问答准确率来测试记忆系统
  • Agent 记忆：AI Agent 在长期交互中存储和回忆历史信息的能力，是其执行复杂任务的基础
  • Pareto 前沿：在多目标优化中，无法在不牺牲某一指标的情况下改善另一指标的最优状态集合
  • 知识工作 persona：模拟知识工作者角色的虚拟用户画像，每个包含约 50 万 token 的历史消息

论文提出 DolphinBench 基准，直接通过 Agent 的任务完成度评估记忆能力，而非传统对话问答格式。基准包含三个知识工作 persona，每个约 50 万 token 历史消息和 200 个任务，所有任务经验证需历史信息才能成功。评估要求同时报告成本、延迟和准确率，以映射 Agent 记忆的 Pareto 前沿。

与你相关：现有记忆基准多为问答形式且只考核准确率，导致记忆系统可通过不合理的时间和成本换取高分，DolphinBench 填补了这一评估空白。
