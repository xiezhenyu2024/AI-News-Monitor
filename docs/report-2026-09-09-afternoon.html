#1 谷歌DeepMind发布AlphaGenome Atlas：绘制人类基因组90亿个单碱基变异的分子效应图谱

关键实体

#6 新研究：AI'外挂'进化与模型微调结合时，模仿学习反而导致性能全面下降

关键实体
  • Agent harness：围绕AI模型的外部配置系统，包括系统提示词、可用工具、执行钩子和上下文管理框架，相当于模型的'外挂装备'。
  • 模仿学习：一种训练方法，让模型学习模仿专家（通常是更强模型）的完整行为轨迹。

该研究探讨了AI智能体的'外挂'（harness）进化与模型微调如何结合。结果发现，在进化后的外挂下，用更强专家的完整轨迹训练较弱模型会导致其在全部7个企业任务上性能下降4到30分，而同样的训练在未进化的外挂下却有效。研究分析了这一反直觉现象的原因。

与你相关：揭示了AI智能体训练中一个重要的反直觉陷阱，对如何有效结合外挂进化与模型微调具有直接指导意义，可帮助避免资源浪费。

#7 新方法CST：让循环神经网络突破训练长度限制，实现超长上下文建模

关键实体
  • 循环神经网络：一类能处理序列数据的神经网络，通过内部状态记忆历史信息，但训练时易出现梯度消失/爆炸。
  • BPTT：随时间反向传播，是训练循环神经网络的标准算法，但在长序列上效果不佳。
  • CST：论文提出的'时间信用稳定化'方法，通过干预反向传播中的状态信用信号来稳定训练。

该论文针对循环神经网络难以外推到更长训练序列的问题，提出'时间信用稳定化'（CST）方法。CST在反向传播时局部重新缩放状态信用信号，稳定其范数而不改变修正方向，且不改变前向计算。在合成任务和真实数据上，CST均显著提升了模型在超长序列上的表现。

与你相关：为构建高效的长上下文模型提供了新路径，循环网络相比Transformer在推理成本上更有优势，此突破可能推动更实用的长文本AI应用。
